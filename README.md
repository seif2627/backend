# DreamCanvas AI Studio

A fully functional single-page experience for an AI image creation website. The site is wired with placeholder interactions to simulate prompting, style selection, generation progress, downloads, favorites, and a saved gallery.

## Getting started
1. Open `index.html` in your browser to view the experience locally.
2. Use the prompt field and style chips to simulate an image generation.
3. Save results to the gallery, shuffle or clear saved items, and explore style previews and FAQs.

All assets are client-side and rely on placeholder Unsplash images for previews.
